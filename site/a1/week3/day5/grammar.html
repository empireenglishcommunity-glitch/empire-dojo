📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

Numbers, 'there is/are' + time prepositions (at/in/on)

الأرقام و there is/are وحروف الوقت (at/in/on)

🧩 The Pattern / النمط

There is + singular | There are + plural | at TIME · on DAY · in MONTH/YEAR

[There are] + [seven days] + [in a week]

⚡ AT a clock time · ON a day/date · IN a month/year. There IS + one, there ARE + many.

AT للساعة، ON لليوم، IN للشهر/السنة. و there is للمفرد و there are للجمع.

📍 When to use it / امتى تستخدمه

Use there is / there are to say that something exists, and at/on/in to place events in time.

نستخدم there is/are للتعبير عن وجود شيء، و at/on/in لتحديد الوقت.

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Arabic uses 'يوجد/في' for existence without number agreement, so is/are gets mixed. Arabic also uses 'في' for almost every time expression, while English splits it into at, on and in.

💡 Examples / أمثلة

There are seven days in a week.

يوجد سبعة أيام في الأسبوع

[There are] + [seven days]

The class is at three o'clock.

الحصة في الساعة الثالثة

[at] + [3 o'clock]

My birthday is in June.

عيد ميلادي في يونيو

[in] + [June]

I work on Monday.

أعمل يوم الاثنين

[on] + [Monday]

There is a book on the table.

يوجد كتاب على الطاولة

[There is] + [a book]

🚫 Common mistakes / أخطاء شائعة

❌ There is seven days.

✅ There are seven days.

Plural noun needs 'there ARE'.

❌ I work in Monday.

✅ I work on Monday.

Days take ON, not IN.

❌ The class is in three o'clock.

✅ The class is at three o'clock.

Clock times take AT.

🧠 Remember it / افتكرها

Smallest to biggest: AT (time) → ON (day) → IN (month).

🎙️ Use it when you speak / استخدمها وانت بتتكلم

Say your schedule: 'There are five lessons. My class is at nine on Sunday.'
