📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

Present simple (I/you/we/they)

المضارع البسيط مع I/you/we/they

🔎 In short / بإيجاز

Talk about routines and habits with the base verb; negatives with don't; time adverbs (every day, always, usually).

المضارع البسيط للروتين مع I/you/we/they، والنفي بـ don't.

🧩 The Pattern / النمط

Subject + base verb + object | Negative: Subject + don't + base verb

[I] + [get up] + [at seven]

⚡ I/you/we/they + base verb (no ending). Negative = don't + base verb.

I/you/we/they مع الفعل المجرد بدون إضافة. والنفي بـ don't + الفعل.

📍 When to use it / امتى تستخدمه

Use the present simple for daily routines, habits and things that are always true.

نستخدم المضارع البسيط للروتين اليومي والعادات والحقائق الدائمة.

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Arabic conjugates the verb itself for every person, so learners look for an ending on English verbs too. With I/you/we/they the English verb takes NO ending at all.

💡 Examples / أمثلة

I get up at seven.

أصحى الساعة سبعة

[I] + [get up] + [at seven]

We eat breakfast together.

نفطر مع بعض

[We] + [eat] + [breakfast]

They don't work on Friday.

لا يعملون يوم الجمعة

[They] + [don't] + [work]

You study every day.

تدرس كل يوم

[You] + [study] + [every day]

I don't drink coffee.

لا أشرب قهوة

[I] + [don't] + [drink]

🚫 Common mistakes / أخطاء شائعة

❌ I am go to work.

✅ I go to work.

Do not add 'am' before a normal verb.

❌ They not work.

✅ They don't work.

Negatives need DON'T + base verb.

❌ I gets up early.

✅ I get up early.

Only he/she/it add -s (next week).

✍️ Practice / تمرين

Fill in the blank. Completing all of them marks this exercise done. / املا الفراغ. لما تخلص كلهم التمرين يتحسب.

I ___ (wake) up at six.

We ___ (not eat) meat.

They ___ (study) English.

You ___ (work) very hard.

I ___ (not like) tea.

🧠 Remember it / افتكرها

No -s for I, YOU, WE, THEY.

🎙️ Use it when you speak / استخدمها وانت بتتكلم

Describe your day: 'I get up at seven, I eat breakfast and I go to work. I don't watch TV in the morning.'

Completes automatically when you finish the practice. / بيتقفل تلقائيًا لما تخلص التمرين.
