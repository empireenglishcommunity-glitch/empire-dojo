📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

'How much / how many' + shopping language

how much / how many ولغة الشراء

🔎 In short / بإيجاز

Ask about price (how much) and quantity (how many); request with I'd like; use this/that/these/those.

السؤال عن السعر والكمية، والطلب بـ I'd like.

🧩 The Pattern / النمط

How much + uncountable | How many + countable plural | I'd like + noun

[How many] + [apples] + [do you want]?

⚡ Can you count it? → HOW MANY. Can't count it (money, water, rice)? → HOW MUCH.

لو ينفع تعدّه → how many. لو مش ينفع (فلوس، ماء، أرز) → how much.

📍 When to use it / امتى تستخدمه

Use 'how much' for price and for things you cannot count, 'how many' for things you can count, and 'I'd like' to order politely.

نستخدم how much للسعر وللأشياء غير المعدودة، و how many للمعدودة، و I'd like للطلب بأدب.

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Arabic uses 'كم' for both countable and uncountable, so the much/many split must be learned. Also 'I want' is normal in Arabic but sounds blunt in English shops — 'I'd like' is the polite form.

💡 Examples / أمثلة

How much is this?

بكم هذا؟

[How much] + [is this]?

How many apples?

كم تفاحة؟

[How many] + [apples]?

I'd like two, please.

أريد اثنين لو سمحت

[I'd like] + [two]

How much money do you have?

كم معك من نقود؟

[How much] + [money]

It costs fifteen pounds.

سعره خمسة عشر جنيهًا

[It costs] + [15 pounds]

🚫 Common mistakes / أخطاء شائعة

❌ How much apples?

✅ How many apples?

Apples are countable → HOW MANY.

❌ How many money?

✅ How much money?

Money is uncountable → HOW MUCH.

❌ I want two.

✅ I'd like two, please.

'I'd like' is the polite shop form.

✍️ Practice / تمرين

Fill in the blank. Completing all of them marks this exercise done. / املا الفراغ. لما تخلص كلهم التمرين يتحسب.

How ___ is this shirt?

How ___ people are there?

How ___ water do you drink?

I ___ like one kilo, please.

How ___ eggs do we need?

🧠 Remember it / افتكرها

MANY = numbers. MUCH = amounts.

🎙️ Use it when you speak / استخدمها وانت بتتكلم

Role-play a shop: 'How much is this? I'd like two, please. How many do you have?'

Completes automatically when you finish the practice. / بيتقفل تلقائيًا لما تخلص التمرين.
