📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

Obligation & advice: have to / must / should

الإلزام والنصيحة: have to / must / should

🔎 In short / بإيجاز

Express necessity with have to / must, absence of obligation with don't have to, and advice with should.

التعبير عن الضرورة بـ have to / must، وغياب الإلزام بـ don't have to، والنصيحة بـ should.

🧩 The Pattern / النمط

have to / must + base (necessity) · don't have to (no obligation) · should + base (advice)

[You] + [should] + [see] + [a doctor]

⚡ Necessity → have to / must. No obligation → don't have to. Prohibited → mustn't. Advice → should.

ضرورة → have to / must. لا إلزام → don't have to. ممنوع → mustn't. نصيحة → should.

📍 When to use it / امتى تستخدمه

Use have to / must for necessity, don't have to for no obligation, and should for advice.

نستخدم have to / must للضرورة، و don't have to لغياب الإلزام، و should للنصيحة.

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Learners add 'to' after must/should ('I must to go'), and confuse 'mustn't' (prohibited) with 'don't have to' (optional).

💡 Examples / أمثلة

I have to work tomorrow.

يجب أن أعمل غدًا

[have to] + [work]

You must wear a seatbelt.

يجب أن ترتدي حزام الأمان

[must] + [wear]

You should see a doctor.

يجب أن ترى طبيبًا (نصيحة)

[should] + [see]

We don't have to hurry.

لسنا مضطرين للعجلة

[don't have to] + [hurry]

You mustn't smoke here.

ممنوع أن تدخّن هنا

[mustn't] + [smoke]

🚫 Common mistakes / أخطاء شائعة

❌ I must to go.

✅ I must go.

No 'to' after must/should.

❌ You don't must be late.

✅ You mustn't be late.

Prohibition = mustn't.

❌ You mustn't pay (it's optional).

✅ You don't have to pay.

No obligation = don't have to; mustn't = prohibited.

🧠 Remember it / افتكرها

SHOULD = advice · MUST/HAVE TO = necessary · MUSTN'T = forbidden.

🎙️ Use it when you speak / استخدمها وانت بتتكلم

Give rules and advice: 'At work I have to arrive early, but I don't have to wear a suit. You should get more sleep.'
