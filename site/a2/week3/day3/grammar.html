📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

Comparative adjectives (-er / more … than)

صفات المقارنة (-er / more … than)

🔎 In short / بإيجاز

Compare two things with -er than for short adjectives and more ... than for longer ones.

المقارنة بين شيئين بـ -er than للصفات القصيرة و more ... than للطويلة.

🧩 The Pattern / النمط

Short adj + -er + than · Long adj: more + adj + than

[Cairo] + [is bigger than] + [Aswan]

⚡ 1-2 syllables → -er. 3+ syllables → more. Always + than. Never both.

مقطع أو اثنان → -er. ثلاثة أو أكثر → more. ودائمًا + than. ومتستخدمش الاتنين.

📍 When to use it / امتى تستخدمه

Compare two things: short adjectives take -er, longer adjectives take 'more', and both are followed by 'than'.

للمقارنة بين شيئين: الصفات القصيرة تأخذ -er، والطويلة تأخذ more، والاتنين يتبعهم than.

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Arabic uses one comparative pattern (أكبر من) for all adjectives, so learners mix '-er' and 'more' (e.g. 'more bigger') and sometimes drop 'than'.

💡 Examples / أمثلة

Cairo is bigger than Aswan.

القاهرة أكبر من أسوان

[bigger than]

This book is more interesting than that one.

هذا الكتاب أكثر تشويقًا

[more … than]

She is taller than me.

هي أطول مني

[taller than]

Today is hotter than yesterday.

اليوم أحرّ من أمس

[hotter than]

Flying is more expensive than the train.

الطيران أغلى من القطار

[more expensive than]

🚫 Common mistakes / أخطاء شائعة

❌ Cairo is more big than Aswan.

✅ Cairo is bigger than Aswan.

Short adjective → -er, not 'more'.

❌ This is more interesting that that.

✅ This is more interesting than that.

Use 'than', not 'that', in comparisons.

❌ She is more taller.

✅ She is taller.

Never use 'more' with an -er adjective.

🧠 Remember it / افتكرها

Short word → -ER. Long word → MORE. Never MORE + -ER.

🎙️ Use it when you speak / استخدمها وانت بتتكلم
