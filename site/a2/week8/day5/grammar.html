📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

Countable/uncountable + quantifiers

المعدود/غير المعدود ومحدّدات الكمية

🧩 The Pattern / النمط

many / a few + countable plural · much / a little + uncountable · a lot of + both

[a few] + [apples] · [a little] + [sugar]

⚡ Countable → many / a few. Uncountable → much / a little. Both → a lot of.

معدود → many / a few. غير معدود → much / a little. الاتنين → a lot of.

📍 When to use it / امتى تستخدمه

Choose the quantifier by the noun: countable (apples) vs uncountable (water, sugar, money).

اختر محدّد الكمية حسب الاسم: معدود (تفاح) مقابل غير معدود (ماء، سكر، فلوس).

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Arabic doesn't split nouns into countable/uncountable the same way, so learners say 'many money' or 'much people' and use 'a few' with uncountables.

💡 Examples / أمثلة

There isn't much sugar.

مافيش سكر كتير

[much] + [uncountable]

I have a few friends.

عندي بعض الأصدقاء

[a few] + [countable]

How many eggs do we need?

كم بيضة نحتاج؟

[How many] + [countable]

We have a little time.

عندنا وقت قليل

[a little] + [uncountable]

There's a lot of water.

يوجد ماء كثير

[a lot of] + [uncountable]

🚫 Common mistakes / أخطاء شائعة

❌ I have many money.

✅ I have a lot of money.

Money is uncountable → much / a lot of.

❌ There are much people.

✅ There are many people.

People is countable → many.

❌ A few water.

✅ A little water.

Uncountable → a little, not a few.
