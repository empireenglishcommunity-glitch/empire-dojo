📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

First conditional + time clauses (real future)

الشرط الأول + جُمل الزمن (المستقبل الواقعي)

🧩 The Pattern / النمط

If / when / as soon as / until + present simple, ... will + verb

[If it rains], [we'll stay home] // [I'll call you] [when I arrive]

⚡ If/when + PRESENT simple, ... WILL + verb. Never 'will' in the if/when half.

If/when + مضارع بسيط، ... WILL + فعل. لا تضع 'will' في نصف الشرط.

📍 When to use it / امتى تستخدمه

For real, likely future situations: the condition/time clause uses the PRESENT simple, and the result uses WILL. Same rule after time words: when, as soon as, before, after, until.

لمواقف مستقبلية واقعية محتملة: جملة الشرط/الزمن بالمضارع البسيط، والنتيجة بـ will. نفس القاعدة بعد كلمات الزمن: when, as soon as, until.

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Learners put 'will' in BOTH halves ('If it will rain, we will stay') because Arabic uses a future marker in the condition too. English keeps the if/when clause in the present simple.

💡 Examples / أمثلة

If it rains, we'll stay at home.

إذا أمطرت، سنبقى في البيت

If + [present], [will]

I'll call you when I arrive.

سأتصل بك عندما أصل

[will] + when + [present]

As soon as she finishes, we'll leave.

بمجرد أن تنتهي، سنغادر

As soon as + [present], [will]

We won't start until everyone is here.

لن نبدأ حتى يصل الجميع

[won't] + until + [present]

If you study hard, you'll pass.

إذا ذاكرت بجد، ستنجح

If + [present], [will]

🚫 Common mistakes / أخطاء شائعة

❌ If it will rain, we will stay home.

✅ If it rains, we'll stay home.

The if-clause uses the present simple, not will.

❌ I will call you when I will arrive.

✅ I'll call you when I arrive.

After 'when' for the future, use the present simple.

❌ We will start until everyone comes.

✅ We won't start until everyone comes.

'until' needs the negative result here + present simple.

🧠 Remember it / افتكرها

The 'if/when' half stays in the present; only the result gets 'will'.
