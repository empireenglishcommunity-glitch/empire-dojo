📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

Second conditional (unreal / hypothetical present)

الشرط الثاني (غير الواقعي / الافتراضي في الحاضر)

🔎 In short / بإيجاز

Hypothetical/unreal present or future: if + past simple, would + base verb.

الافتراض غير الواقعي في الحاضر/المستقبل: if + ماضٍ بسيط، would + الفعل.

🧩 The Pattern / النمط

If + past simple, ... would + verb · If I were you, I'd ...

[If I had money], [I would travel] // [If I were you], [I'd apologise]

⚡ Imaginary now → If + PAST simple, ... WOULD + verb. Advice → 'If I were you, I'd ...'.

خيالي الآن → If + ماضٍ بسيط، ... WOULD + فعل. نصيحة → 'If I were you, I'd ...'.

📍 When to use it / امتى تستخدمه

For imaginary, unlikely or impossible present/future situations, and for advice. The if-clause uses the PAST simple (with 'were' for all persons after if), and the result uses WOULD + verb.

لمواقف خيالية أو غير محتملة في الحاضر/المستقبل، وللنصيحة. جملة الشرط بالماضي البسيط (مع 'were' لكل الضمائر بعد if)، والنتيجة بـ would + فعل.

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

The 'unreal' meaning is carried by a past-tense form that doesn't mean past time, which is confusing. Learners say 'If I would have money' or use 'was' instead of the recommended 'were' ('If I were you').

💡 Examples / أمثلة

If I had a lot of money, I would travel the world.

لو كان لديّ مال كثير، لسافرت حول العالم

If + [past], [would]

If I were you, I'd apologise.

لو كنت مكانك، لاعتذرت

If + were, [I'd]

She would help if she had time.

كانت ستساعد لو كان لديها وقت

[would] + if + [past]

What would you do if you won the lottery?

ماذا كنت ستفعل لو ربحت اليانصيب؟

[would + do] + if + [won]?

If he studied more, he'd pass easily.

لو ذاكر أكثر، لنجح بسهولة

If + [past], [he'd]

🚫 Common mistakes / أخطاء شائعة

❌ If I would have money, I would travel.

✅ If I had money, I would travel.

The if-clause uses the past simple, never 'would'.

❌ If I was you, I'd wait.

✅ If I were you, I'd wait.

In this fixed advice pattern we use 'were' for all persons.

❌ If she has time, she would help. (imagining)

✅ If she had time, she would help.

Unreal present → past simple in the if-clause.

✍️ Practice / تمرين

Fill in the blank. Completing all of them marks this exercise done. / املا الفراغ. لما تخلص كلهم التمرين يتحسب.

If I ___ (be) rich, I would buy a house by the sea.

She would travel more if she ___ (have) more holidays.

If I were you, I ___ (take) the job.

What would you do if you ___ (lose) your phone?

If he ___ (study) harder, he'd get better marks.

🧠 Remember it / افتكرها

Dream world: past-tense 'if' + 'would' result. 'Were' for everyone in 'If I were you'.

🎙️ Use it when you speak / استخدمها وانت بتتكلم

In accent week 5 you practised weak would/'d and 'if I were'. Say: 'If I were you, I'd wait' — weak 'were', contracted 'I'd', stress on the advice verb.
