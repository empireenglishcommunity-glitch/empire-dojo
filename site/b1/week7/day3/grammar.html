📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

Present perfect continuous (have been + -ing)

المضارع التام المستمر (have been + -ing)

🔎 In short / بإيجاز

Recent or ongoing activity emphasising duration: have/has been + -ing; how long, for/since.

نشاط مستمر أو حديث مع التركيز على المدة: have/has been + -ing؛ how long وfor/since.

🧩 The Pattern / النمط

have/has + been + verb-ing · for + period · since + point · How long ...?

[I've been waiting] + [for two hours]

⚡ Still going + how long → have/has BEEN + -ing (for a period, since a point). State verbs → simple present perfect.

مستمر + المدة → have/has BEEN + -ing (for للمدة، since للنقطة). أفعال الحالة → مضارع تام بسيط.

📍 When to use it / امتى تستخدمه

For an action that started in the past and is still continuing (or just stopped, with a visible result). It emphasises the DURATION or the activity itself, often answering 'How long ...?'.

لفعل بدأ في الماضي ولا يزال مستمرًا (أو توقّف للتوّ ونتيجته ظاهرة). يركّز على المدة أو النشاط نفسه، وغالبًا يجيب على 'How long?'.

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

There is no equivalent form in Arabic, so learners use the present simple ('I wait here since two hours') or drop 'been' ('I have waiting'). They also use it with state verbs like know/be, which prefer the simple present perfect.

💡 Examples / أمثلة

I've been waiting for two hours.

أنتظر منذ ساعتين

[have been waiting] + [for]

She's been studying since morning.

تدرس منذ الصباح

[has been studying] + [since]

How long have you been learning English?

منذ متى تتعلم الإنجليزية؟

How long + [have been + -ing]?

It's been raining all day.

تمطر طوال اليوم

[has been raining]

Your eyes are red — have you been crying?

عيناك حمراء — هل كنت تبكي؟

[have been + -ing]? (visible result)

🚫 Common mistakes / أخطاء شائعة

❌ I am waiting here since two hours.

✅ I've been waiting here for two hours.

Duration up to now → have been + -ing, and 'for' with a period.

❌ I have waiting for an hour.

✅ I have been waiting for an hour.

The form needs 'been' before the -ing verb.

❌ I've been knowing her for years.

✅ I've known her for years.

State verbs (know, be, own) use the simple present perfect.

✍️ Practice / تمرين

Fill in the blank. Completing all of them marks this exercise done. / املا الفراغ. لما تخلص كلهم التمرين يتحسب.

I ___ (wait) for the bus for 20 minutes.

🧠 Remember it / افتكرها

'How long?' → have been + -ing. Don't forget BEEN.
