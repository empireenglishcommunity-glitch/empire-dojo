📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

used to / would for past habits

used to / would للعادات في الماضي

🔎 In short / بإيجاز

Past habits and states no longer true with used to; would for repeated past actions.

عادات وحالات ماضية لم تعد قائمة بـ used to؛ وwould للأفعال المتكررة في الماضي.

🧩 The Pattern / النمط

used to + verb (past habit or state, not now) · would + verb (repeated past action) · didn't use to / Did you use to ...?

[I used to play] + [football every Friday]

⚡ Past habit or state, not now → used to + verb. Repeated past action in a memory → would + verb. Negative/question → use to.

عادة أو حالة ماضية انتهت → used to + فعل. فعل متكرر في الذكريات → would + فعل. النفي/السؤال → use to.

📍 When to use it / امتى تستخدمه

'used to + verb' describes a past habit or state that is no longer true. 'would + verb' also describes repeated past ACTIONS in a story or memory, but not past states. In negatives and questions the 'd' disappears: didn't use to / Did you use to ...?

'used to + فعل' لعادة أو حالة في الماضي لم تعد موجودة. 'would + فعل' لأفعال متكررة في الماضي (لا للحالات). في النفي والسؤال: didn't use to / Did you use to ...?

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Arabic uses كان + المضارع for both habits and states, so learners over-use 'would' for states ('I would have long hair') and add -ed twice ('didn't used to'). They also confuse 'used to + verb' with 'be used to + -ing' (= be accustomed).

💡 Examples / أمثلة

I used to play football every Friday.

كنت ألعب كرة القدم كل جمعة

[used to + verb] (habit)

She used to have long hair.

كان شعرها طويلاً

[used to + have] (state)

Every summer we would visit my grandmother.

كل صيف كنا نزور جدتي

[would + verb] (repeated action)

I didn't use to like coffee.

لم أكن أحب القهوة

[didn't use to] (negative)

Did you use to walk to school?

هل كنت تمشي إلى المدرسة؟

[Did + use to]?

🚫 Common mistakes / أخطاء شائعة

❌ I didn't used to like it.

✅ I didn't use to like it.

After 'didn't' the base form is 'use to', without -d.

❌ I would have long hair.

✅ I used to have long hair.

'would' works for repeated actions, not past states.

❌ I am used to play football. (past habit)

✅ I used to play football.

'be used to' + -ing means 'accustomed to'; a past habit is 'used to + verb'.

🧠 Remember it / افتكرها

States need 'used to'. Actions accept 'would'. After 'did', drop the 'd'.

🎙️ Use it when you speak / استخدمها وانت بتتكلم

In accent week 8 you practised 'used to' as /juːstə/ and would → 'd. Say: 'I used to play football' as 'I juːstə play' — one smooth weak group, stress on 'PLAY'.
