📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

Emphasis: cleft sentences and so/such ... that

التوكيد: الجُمل المشقوقة و so/such ... that

🔎 In short / بإيجاز

Add emphasis with cleft sentences (It was… that; What I need is…) and so/such … that.

إضافة التوكيد بالجُمَل المشقوقة (It was… that؛ What I need is…) و so/such … that.

🧩 The Pattern / النمط

It + be + X + that/who ... · What + clause + be + X · All (that) + clause + be + X · so + adjective + that · such a + adjective + noun + that · emphatic do/did

[It was Sara that called] // [What I need is a holiday]

⚡ It + be + X + that (spotlight) · What ... is (delay then reveal) · so + adjective / such a + adjective + noun · stressed do/did to insist.

It + be + X + that (إبراز) · What ... is (تأخير ثم كشف) · so + صفة / such a + صفة + اسم · do/did منبورة للإصرار.

📍 When to use it / امتى تستخدمه

To highlight one part of a sentence. 'It was X that...' spotlights a person, time or thing. 'What... is...' delays and then reveals the key point. 'so/such... that' intensifies with a result. Emphatic 'do/did' insists or contradicts. These structures make speech persuasive rather than merely correct.

لتسليط الضوء على جزء من الجملة. 'It was X that' تُبرز شخصًا أو وقتًا. و'What... is...' تؤخّر ثم تكشف النقطة. و'so/such...that' للتكثيف مع نتيجة. و'do/did' للإصرار.

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Arabic emphasises with particles (إنّ) and flexible word order, so learners translate directly and produce flat English. They also confuse 'so' with 'such' because both map to جدًا, and they overlook emphatic 'do' entirely since Arabic has no equivalent auxiliary.

💡 Examples / أمثلة

It was Sara that called, not Mona.

سارة هي التي اتصلت، لا منى

It + was + [X] + that + clause

What I really need is a holiday.

ما أحتاجه فعلاً هو عطلة

What + [clause] + is + [X]

It was so cold that the pipes froze.

كان الجو باردًا جدًا حتى تجمّدت الأنابيب

so + [adjective] + that + [result]

It was such a long day that I fell asleep.

كان يومًا طويلاً جدًا حتى نمت

such a + [adj + noun] + that

I did tell you — you weren't listening!

لقد أخبرتك فعلاً — لم تكن تسمع!

[emphatic did + verb]

🚫 Common mistakes / أخطاء شائعة

❌ It was such cold that the pipes froze.

✅ It was so cold that the pipes froze.

'so' goes with an adjective alone; 'such a' needs a noun.

❌ It was so a long day that I fell asleep.

✅ It was such a long day that I fell asleep.

With adjective + noun use 'such a', not 'so'.

❌ What I need it is a holiday.

✅ What I need is a holiday.

Don't add an extra pronoun — 'what' already stands for the object.

🧠 Remember it / افتكرها

so + adjective alone · such a + adjective + noun. 'It was X that' puts the spotlight on X.

🎙️ Use it when you speak / استخدمها وانت بتتكلم

In accent week 15 you drilled where the main stress falls in each structure. These forms only work if you stress the spotlighted element — said flat, a cleft sentence carries no emphasis at all.
