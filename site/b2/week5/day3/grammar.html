Third conditional (unreal past)

الشرط الثالث (الماضي غير الواقعي)

🔎 In short / بإيجاز

Talk about unreal/imagined past and its imagined result: if + past perfect, would have + past participle.

الحديث عن ماضٍ غير واقعي ونتيجته المتخيّلة: if + past perfect، would have + التصريف الثالث.

🧩 The Pattern / النمط

If + had + participle, ... would have + participle · wouldn't have · could/might have

[If I'd known], [I would have called]

⚡ If + HAD + participle, ... WOULD HAVE + participle. Never 'would have' in the if-half. Never write 'would of'.

If + HAD + التصريف الثالث، ... WOULD HAVE + التصريف الثالث. لا 'would have' في نصف الشرط، ولا تكتب 'would of'.

📍 When to use it / امتى تستخدمه

For an imaginary past — something that did NOT happen, and its imaginary result. Used for regret, criticism and explanation. The if-clause takes the past perfect; the result takes 'would have + participle'. Swap 'would' for 'could' or 'might' to soften certainty.

لماضٍ خيالي — شيء لم يحدث ونتيجته المتخيّلة. يُستخدم للأسف والنقد والتفسير. جملة الشرط بالماضي التام والنتيجة would have + التصريف الثالث.

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Arabic uses لو + الماضي for both second and third conditionals, so learners can't feel the difference. The biggest error is putting 'would have' in the if-clause ('if I would have known'), and writing 'would of' because that is exactly how /wʊdəv/ sounds.

💡 Examples / أمثلة

If I'd known, I would have called you.

لو كنت أعرف، لكنت اتصلت بك

If + [had + participle], [would have + participle]

We wouldn't have missed the train if we'd left earlier.

لم نكن سنفوّت القطار لو خرجنا أبكر

[wouldn't have + participle] + if + [had + participle]

You should have told me — I could have helped.

كان عليك أن تخبرني — كنت أستطيع المساعدة

[should have] / [could have + participle]

If she hadn't helped me, I would have failed.

لو لم تساعدني، لكنت فشلت

If + [hadn't + participle], [would have]

It might have worked if we'd tried harder.

ربما كان سينجح لو حاولنا أكثر

[might have + participle] + if + [had]

🚫 Common mistakes / أخطاء شائعة

❌ If I would have known, I would have called.

✅ If I'd known, I would have called.

The if-clause uses the past perfect only — never 'would have'.

❌ I would of called you.

✅ I would have called you. / I would've called you.

'would've' is 'would have'; 'would of' does not exist in writing.

❌ If I had known, I would call you.

✅ If I had known, I would have called you.

An unreal PAST result needs 'would have + participle', not 'would + verb'.

✍️ Practice / تمرين

Fill in the blank. Completing all of them marks this exercise done. / املا الفراغ. لما تخلص كلهم التمرين يتحسب.

If I ___ (know), I would have called.

We wouldn't have missed it if we ___ (leave) earlier.

You ___ (should / tell) me about it.

If she hadn't helped, I ___ (fail).

It ___ (might / work) if we'd tried harder.

🧠 Remember it / افتكرها

Past that never happened: 'had' in the if-half, 'would have' in the result.

🎙️ Use it when you speak / استخدمها وانت بتتكلم

In accent week 5 you drilled /wʊdəv/ as one unit and 'if I'd known'. Say 'If I'd KNOWN, I would've CALLED ↘' with a falling regretful tone — and never let it become 'would of'.
