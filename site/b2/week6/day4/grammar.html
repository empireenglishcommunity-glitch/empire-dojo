Mixed conditionals (crossing time frames)

الشروط المختلطة (تقاطع الأزمنة)

🧩 The Pattern / النمط

If + had + participle, ... would + verb (past cause → present result) · If + past simple, ... would have + participle (present cause → past result)

[If I'd studied medicine], [I'd be a doctor now] // [If I weren't so shy], [I'd have spoken up]

⚡ Past cause + present result → If + had + participle, would + verb. Present cause + past result → If + past simple, would have + participle. Add a time word.

سبب ماضٍ + نتيجة حاضرة → If + had، would + فعل. سبب حاضر + نتيجة ماضية → If + ماضٍ بسيط، would have + التصريف الثالث.

📍 When to use it / امتى تستخدمه

When the condition and the result belong to DIFFERENT times. Type A: a past action with a present consequence — 'If I'd studied medicine, I'd be a doctor now.' Type B: a permanent present quality with a past consequence — 'If I weren't so shy, I'd have spoken up.' A time word ('now', 'yesterday') makes it clear.

عندما ينتمي الشرط والنتيجة لزمنين مختلفين. النوع الأول: فعل ماضٍ بنتيجة حاضرة. النوع الثاني: صفة حاضرة دائمة بنتيجة ماضية. وكلمة زمن توضّح المعنى.

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Learners memorise the three 'pure' conditionals as fixed templates, so mixing them feels like breaking a rule. In speech the distinction is only /dbi/ versus /dəv/, so even correct writing often comes out ambiguous when spoken.

💡 Examples / أمثلة

If I'd studied medicine, I'd be a doctor now.

لو درست الطب، لكنت طبيبًا الآن

If + [had + participle], [would + verb] (present result)

If she'd taken that job, she'd be living in Paris.

لو أخذت تلك الوظيفة، لكانت تعيش في باريس

If + [had], [would be + -ing]

If I weren't so tired, I'd have gone out last night.

لو لم أكن متعبًا، لكنت خرجت ليلة أمس

If + [past simple], [would have + participle]

If he didn't work nights, he'd have come with us.

لو لم يعمل ليلاً، لكان جاء معنا

If + [didn't + verb], [would have]

If we'd saved more, we'd be able to buy a house.

لو وفّرنا أكثر، لكنّا قادرين على شراء بيت

If + [had], [would be able to]

🚫 Common mistakes / أخطاء شائعة

❌ If I'd studied medicine, I'd have been a doctor now.

✅ If I'd studied medicine, I'd be a doctor now.

'now' signals a present result → 'would be', not 'would have been'.

❌ If I wasn't so tired, I'd go out last night.

✅ If I weren't so tired, I'd have gone out last night.

'last night' is a past result → 'would have gone'.

❌ If I would have studied medicine, I'd be a doctor.

✅ If I'd studied medicine, I'd be a doctor.

The if-clause never takes 'would have'.

🧠 Remember it / افتكرها

Look at the RESULT's time, not the condition's: 'now' → would be · 'yesterday' → would have been.

🎙️ Use it when you speak / استخدمها وانت بتتكلم

In accent week 6 you drilled /dbi/ against /dəv/ and stressing the time anchor. Say 'I'd BE a doctor NOW' against 'I'd've BEEN a doctor' — the anchor tells your listener which time frame you mean.
