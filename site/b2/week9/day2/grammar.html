📅 This week's pattern / نمط الأسبوع

One pattern per week — it stays the same all week, so practise it every day. / نمط واحد كل أسبوع — بيفضل نفسه طول الأسبوع، فاتمرن عليه كل يوم.

Passive (all tenses) + causative have/get something done

المبني للمجهول (كل الأزمنة) + الصيغة السببية have/get something done

🔎 In short / بإيجاز

Use the passive across tenses and with modals; and have/get something done for services.

استخدام المبني للمجهول عبر الأزمنة ومع الأفعال الناقصة؛ و have/get something done للخدمات.

🧩 The Pattern / النمط

be (any tense) + participle · is being / has been / had been / will be / to be / modal + be · have/get + object + participle

[The road is being repaired] // [I had my hair cut]

⚡ Passive = be (in any tense) + participle. Causative = have/get + OBJECT + participle (someone else did it for you).

المجهول = be (بأي زمن) + التصريف الثالث. السببية = have/get + المفعول + التصريف الثالث (شخص آخر فعلها لك).

📍 When to use it / امتى تستخدمه

The passive works in every tense by changing 'be': is repaired, is being repaired, has been repaired, had been repaired, will be repaired, must be repaired, to be repaired. The causative 'have/get + object + participle' means you arranged for someone ELSE to do it: 'I had my hair cut.'

المجهول يعمل في كل الأزمنة بتغيير 'be'. والصيغة السببية 'have/get + مفعول + التصريف الثالث' تعني أنك رتّبت لشخص آخر أن يفعلها: 'I had my hair cut.'

⚠️ Why this is tricky for Arabic speakers / ليه دي صعبة على العربي

Arabic forms the passive by internal vowel change with no auxiliary, so learners drop 'be' or 'been'. The causative is harder still: 'I cut my hair' and 'I had my hair cut' both translate similarly, but in English the first means you did it yourself.

💡 Examples / أمثلة

The road is being repaired at the moment.

الطريق يُصلَح الآن

[is being + participle] (present continuous passive)

The house has already been sold.

البيت بيع بالفعل

[has been + participle] (perfect passive)

The building had been abandoned for years.

المبنى كان مهجورًا لسنوات

[had been + participle] (past perfect passive)

I had my hair cut yesterday.

قصصت شعري أمس (الحلاق قصّه)

[had + object + participle] (causative)

I need to get my car fixed.

أحتاج أن أصلّح سيارتي (شخص آخر)

[get + object + participle] (informal causative)

🚫 Common mistakes / أخطاء شائعة

❌ The house built in 1990.

✅ The house was built in 1990.

The passive always needs a form of 'be' before the participle.

❌ I cut my hair yesterday. (at the barber's)

✅ I had my hair cut yesterday.

If someone else did it for you, use the causative.

❌ I had cut my hair.

✅ I had my hair cut.

Word order: have + OBJECT + participle. 'I had cut' is the past perfect, a different meaning.

🧠 Remember it / افتكرها

No 'be', no passive. Object BEFORE the participle in causatives.

🎙️ Use it when you speak / استخدمها وانت بتتكلم

In accent week 9 you drilled flat auxiliary chains and causative stress. Say 'I had my hair CUT' with the stress on the final participle — that stress is what marks it as a service.
