🏛️ الرسالة والرؤية

🎯 الرسالة / Mission

مساعدة المتعلّم العربي على بناء لغة إنجليزية حقيقية وواثقة وقابلة للاستخدام — عبر ممارسة يومية بسيطة، ومتابعة صادقة، ومجتمع داعم.

🌅 الرؤية / Vision

مجتمع من المتعلّمين يحضرون كل يوم، يدعمون بعضهم، ويحوّلون الجهد الثابت إلى طلاقة — حيث يكون التقدّم شخصياً ومُتتبَّعاً ويُحتفى به.

القيم التشغيلية: صفر إزعاج للطلاب • أي تغيير عبر PR يوافق عليه المالك • اختبارات خضراء قبل الدفع • نسخ احتياطية خارج الموقع • لا حذف لتاريخ Git. Common Sense First 🏛️

🗺️ خريطة المنظومة

ثلاث مستودعات تحت منظّمة empireenglishcommunity-glitch:

🤖 empire-nexus القلب / Backend

بوت Discord التعليمي + بوت التليجرام للإدارة (Empire Ops) + الـ API والخادم. يعمل داخل حاوية empire-english-bot على الخادم (Docker Compose). يخدم bot.empireenglish.online (التغييرات، الجلسات، التقدّم).

📚 empire-dojo صفحة التمرين / Frontend

منصة التمرين practice.empireenglish.online على Cloudflare Pages (مشروع empire-practice). تتضمّن بوابة الحافة functions/_middleware.js ودليل الطالب /guide ودليل الإدارة /ops-guide (هذه الصفحة).

📖 empire-chronicle الذاكرة / Docs

التوثيق، استمرارية الجلسات، الخطط، عمليات التدقيق، ونظام ذاكرة الذكاء الاصطناعي. المرجع التاريخي للقرارات والإجراءات.

🧭 رحلة الطالب (ملخّص)

1
الربط: الطالب يكتب !link في Discord → كود لمرة واحدة (15 دقيقة) → يفتح practice.empireenglish.online → جلسة 60 يوماً.
2
المهام اليومية (7): 5 على المنصة (Accent, Shadowing, Speaking = تسجيل؛ Listening, Vocabulary = تلقائي) + 2 على Discord (Writing, Community).
3
التقدّم: عدّاد موثوق من الخادم؛ إكمال المهام الخمس = يوم أخضر. تزامن عبر الأجهزة.
4
الإتقان + المراجعة: ترقية المستويات (Bronze→Diamond) + مراجعة الكلمات السابقة عبر نظام التكرار المتباعد (SRS).

💬 أوامر الطالب (Discord)

!link
توليد كود دخول للمنصة (لمرة واحدة، صلاحية 15 دقيقة).
!progress

!resetme

🛠️ أوامر الإدارة (Discord)

!reset-student <@user>
بدء إعادة ضبط سجلّ طالب (يأخذ لقطة snapshot أولاً ويسجّل الموافقة).
!restore-student <@user>
استعادة سجلّ طالب من آخر لقطة (شبكة أمان بعد إعادة الضبط).
!approve-reset <id>
الموافقة على طلب إعادة ضبط معلّق.
!deny-reset <id>
رفض طلب إعادة ضبط معلّق.
!setlevel <@user> <L0-L?>
تعيين/تغيير مستوى الطالب.
!announce <msg>
إرسال إعلان للطلاب.

⚖️ الحوكمة — إعادة ضبط سجلّ الطالب

هذا أهمّ سير عمل حسّاس. القاعدة: لا حذف بلا موافقة موثّقة، ولا تنفيذ بلا موافقتك.

1
الطلب: الطالب !resetme (أو الإدارة !reset-student).
2
الموافقة الموثّقة (Consent): تُسجَّل موافقة الطالب في سجلّ الموافقات — دليل دائم أن الحذف تمّ بطلبه.
3
لقطة (Snapshot): يُؤخذ نسخ كامل لسجلّ الطالب قبل أي تغيير (يتيح الاستعادة).
4
موافقة المالك: يدخل الطلب قائمة الانتظار وتصلك إشعارات؛ توافق عبر /approve (تليجرام) أو !approve-reset (Discord).
5
التنفيذ: بعد موافقتك تُنفَّذ إعادة الضبط. الاستعادة ممكنة عبر !restore-student من اللقطة عند الحاجة.

🚀 دليل التشغيل (Runbook)

⚠️ كل التغييرات عبر PR يوافق عليها المالك. الاختبارات يجب أن تكون خضراء قبل الدفع. لا دفع مباشر إلى main. لا إعادة كتابة لتاريخ Git.

1) نشر البوت (empire-nexus)

ssh -i <deploy_key> root@<SERVER_IP> \
  "cd /opt/empire-english-bot && git pull --ff-only && docker compose up -d --build"

2) نشر صفحة التمرين (empire-dojo)

cd empire-dojo
CLOUDFLARE_ACCOUNT_ID=<account_id> CLOUDFLARE_API_TOKEN=<token> \
  npx wrangler pages deploy site --project-name=empire-practice --branch=main

3) الاختبارات

cd empire-nexus/bots/discord-learning-bot
python3.12 -m pytest tests/ -q   # يجب أن تمرّ كلها قبل أي دفع

4) مطابقة/مصالحة البيانات (Reconcile)

docker exec empire-english-bot python3 -m src.reconcile

5) النسخ الاحتياطي والاستعادة

•
محلي: نسخة يومية على الخادم (cron).
•
خارج الموقع (R2): رفع تلقائي إلى Cloudflare R2 — bucket empire-english-backups عبر remote r2 (cron 03:20).
•
تنبيه الحداثة: فحص يومي (cron 04:00) — لو غابت النسخة أو تقادمت، يصلك تنبيه على تليجرام الإدارة.
•
اختبار الاستعادة: جُرِّب واستُعيدت النسخة بنجاح؛ كرّر الاختبار دورياً.
🔑 كل الأسرار (مفاتيح النشر، رموز Cloudflare، مفاتيح R2) تُحفظ خارج المستودعات (على الخادم / أسرار المنصة) — لا تُكتب في أي صفحة أو كود.

👑 الأدوار والقواعد

• المالك (mahmoudashri66-star): القرار النهائي، يوافق على كل PR، ويعتمد إعادة الضبط.

• الإدارة/المشرفون: الدعم اليومي، الإعلانات، مساعدة الطلاب، تصعيد الطلبات الحسّاسة للمالك.

• قاعدة ذهبية: صفر إزعاج للطلاب — أي تغيير يُختبر ويُراجَع أولاً. تحديث الدليل في نفس PR الخاص بأي ميزة.

• الأمان: لا تشارك رمز هذه الصفحة؛ دوّر الرمز عند الحاجة (حدّث الهاش في _middleware.js).
